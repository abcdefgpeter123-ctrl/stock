融資有沒有洗乾淨？
融資餘額是全市場「借錢買股票」的總量。判斷方式：把「融資降幅」除以「指數跌幅」算出比值，比值越高代表籌碼出清越徹底。

解讀參考（指數下跌時）：
🔴 比值 0–25%：幾乎沒洗，籌碼仍重
🟠 比值 25–50%：開始洗，但還不夠
🟡 比值 50–75%：洗得不錯，接近出清
🟢 比值 75% 以上：極端恐慌式出清，斷頭賣壓近尾聲
🔴 指數上漲且融資漲幅 > 指數漲幅：追高加碼，留意過熱

匯率與出口關係
台幣貶值（數字↑）代表每 1 美元換到更多台幣，有利台灣出口商，企業以美元計價的收入折回台幣後增加。

解讀參考：
🟢 > 32：台幣偏弱，有利出口
🟡 30–32：中性區間
🔴 < 30：台幣偏強，不利出口

需要 GitHub Personal Access Token 才能遠端觸發 Actions。
前往 github.com/settings/tokens → 建議用 Fine-grained token：只授權這一個 repo、權限只給 Actions: Read and write、有效期設 30～90 天。
